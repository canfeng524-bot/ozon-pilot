# Ozon 上架流水线（ozon-pilot）

从 1688 链接到 Ozon 上架包的一条命令流水线。

## 用法

首次运行先安装依赖到项目本地目录：

```bash
py -3.12 -m pip install --target .deps -r requirements.txt
```

```bash
# 方式一：直接给链接（自动抓图+建文件夹）
python run.py "https://detail.1688.com/offer/xxxxxxxx.html"

# 方式二：油猴脚本提取的 JSON 放进文件夹后，对文件夹跑（数据更全：标题/价格/属性/件重尺）
python run.py "E:\ozon商品\intake\20260822_新品"

# 跳过所有 AI 环节（只用真实素材合成 + 程序排版）
python run.py <链接或文件夹> --skip-ai

# 保留已核验字段，只刷新 1688 公开主图与详情图
python run.py "E:\ozon商品\intake\20260822_新品" --refresh-images
```

产物（都在商品文件夹里）：
| 文件 | 说明 |
|---|---|
| review.html | 审核页：筛选总表 + 上架图矩阵 + 俄语文案（带中文对照） |
| ozon_listing.xlsx | 导入模板 + 价格测算 |
| remastered/ | 上架图（1350×1800）+ ai_todo.json（待 AI 生成的槽位和提示词） |
| copy_prompt.md | 未配置文案模型时，粘给任意大模型生成 listing.json |
| source/ | 主图 + 详情原图 |
| screen.json | 每张源图的筛选结论 |

最终上架图不得残留供应商页的中文标题、说明或水印。详情图如含中文，必须在 `slots.json` 中用
`{"file":"source/detail/d08.jpg","crop":[left,top,right,bottom]}` 裁出纯商品区域，或重制/留空；
`crop` 支持 0–1 归一化坐标和源图像素坐标。俄文只通过程序排版叠加。

尺寸信息图使用已验证的长宽高和当前 SKU 实拍，只附普通手机（约 7.5×15 cm）作同尺度参照，
避免不同商品混用 A4、平板或其他参照物。内部容量图只能展示有源图/样品证据的内胆、口袋和扣具。

审核页的上架图矩阵必须按 `carousel_plan` 顺序显示，不按文件名字母排序。ZIP 与 Excel 中的图片文件
使用连续两位序号命名，例如 `01_main.jpg`、`02_main_alt.jpg`、`03_model1.jpg`，保证上传顺序明确。

俄语标题按「核心检索词 → 已验证属性词 → 相关场景词」组织。核心词必须在最前，采用俄罗斯买家常用的
自然表达。标题属性词默认不写具体长宽高，尺寸放到属性表、描述和尺寸图。场景词只保留与商品真实用途匹配的
少量长尾词，不逐字翻译中文，不用礼物/家用/通勤等无关词堆砌搜索覆盖。季节或临近节日词必须同时有
商品相关性和当期 Ozon 站内依据，标题最多使用一个，且不能在没有 Seller 搜索数据时声称它是高频热词。

## 配置（config.yaml）

- `prompts.copy_system`：文案提示词。标题固定为“俄罗斯买家会搜索的核心品类词在前 + 已验证属性居中 + 匹配商品的场景词置后”；避免逐字翻译、关键词堆砌和错误人群/用途。
- `image_prompts`：主图/模特图生成提示词
- `carousel_plan`：1张实际首图+1张首图备选+7副图槽位计划（类型/俄语标注/提示词）
- `intake.min_image_short_side_px`：源图短边质量门槛；低于此值的主图与详情图直接从素材池剔除（默认 600px）。
- `models`：三个环节独立配模型——
  - `copy`：文案，OpenAI 兼容接口（deepseek/qwen/gpt 均可）
  - `vision`：图片筛选分类（需视觉模型，如 doubao-vision）
  - `image`：AI 场景图（火山引擎 Seedream）
  - **留空则降级**：筛选退化为启发式、文案退化为提示词文件、AI 图进 ai_todo.json
- `pricing`：价格测算默认参数

## 流程

```
链接/JSON → 下载源图 → 筛选(视觉模型或启发式) → 合成(真实素材+程序排版+AI)
→ 文案(LLM) → review.html + xlsx → 人工审核 → Ozon 后台上架
```

## 真实素材 vs AI 的分工原则

- 白底多角度/细节/内部 → 真实素材裁剪合成（货不对板风险最低）
- 场景模特图（素材里没有）→ AI 生成，提示词强制"严格参考商品图"
- 尺寸信息图 → 程序排版（俄语零乱码）
- 侧/背面、内里、容量、材质微距、可调/可拆肩带、颜色合集 → 必须有对应实拍；没有就不生成
